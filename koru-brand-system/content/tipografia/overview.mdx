## Famílias tipográficas

| Papel | Família | Uso |
|---|---|---|
| Display / Headings | Serif (variável) | h1, h2, títulos de seção |
| Body | Sans-serif (Inter) | Corpo de texto, UI |
| Monospace | Space Mono | Código, metadados, labels |

## Escala

| Token | Uso |
|---|---|
| `text-3xl font-semibold` | Título de página |
| `text-xl font-semibold` | h2 dentro de conteúdo |
| `text-base` | Corpo principal |
| `text-sm` | UI labels, sidebar |
| `text-xs font-mono uppercase tracking-widest` | Categoria / eyebrow |

<Callout type="tip">
  Headings usam a família serif. Todo texto de interface (botões, labels, navegação) usa sans. Código e metadados sempre em Space Mono.
</Callout>
